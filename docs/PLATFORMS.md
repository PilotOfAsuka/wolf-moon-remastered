# Платформа выпуска — Web

По последнему уточнению пользователя готовая игра распространяется только через GitHub Pages. Игрок открывает ссылку в README репозитория и играет в браузере.

Godot **4.7.2**, single-thread WebGL 2. Локально проверены загрузка, новая игра, движение, F2 и сохранение/reload/F9. После текущих исправлений Web повторно экспортирована; репозиторий открыт, публикация Pages переводится на ветку web-build.

macOS Apple M1 используется для разработки, проверки исходного проекта и визуальных тестов. Ранее созданный локальный .app остаётся исследовательским результатом; установочные пакеты в GitHub не публикуются. Windows, Linux, Android и iOS исключены из текущего объёма выпуска.
