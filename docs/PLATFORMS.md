# Платформы

Версия разработки: установленный Godot **4.7.2 stable**, macOS Apple M1.

| Платформа | Фактическая проверка | Статус |
|---|---|---|
| macOS, исходный проект | Headless tests и живой OpenGL renderer, обычное/портретное окно | Запускается |
| macOS, standalone export | Окончательный статус определяется `build/export_macos.log` и журналом запуска | Проверяется |
| Windows | Отдельный запуск не выполнен | Не подтверждено |
| Linux | Отдельный запуск не выполнен | Не подтверждено |
| Android | Устройство/экспорт не проверены | Не подтверждено |
| iOS | Подпись/устройство/экспорт не проверены | Не подтверждено |
| Web | Браузерный экспорт не проверен | Не подтверждено |

Официальный шаблон macOS 4.7.2 получен из пакета Godot с помощью HTTP Range, без скачивания остальных 1.28 GB. Источник/размер/отпечаток: `research/reports/macos_template.json`; инструмент `tools/fetch_macos_template.py`. Для экспорта включён ETC2 ASTC, требуемый шаблоном arm64/universal. Шаблон лежит в локальном кэше и стандартном каталоге Godot; в runtime игры не нужен Java или Python.
